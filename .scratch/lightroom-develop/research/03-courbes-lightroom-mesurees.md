## Lecture (2026-09-11, première passe — chiffres du tableau et des JSON)

**Ton.**
- **Exposition** n'est pas un gain linéaire nu : +1 IL rend 128 → 181 (un ×2 en
  linéaire donnerait 176) et 224 → 245 — un GENOU vers le blanc ; +2 IL : 128 →
  220, 255 tenu. −2 IL : 255 → 197 (le blanc descend).
- **Contraste** : S autour de 128 ; −100 DÉSATURE aussi (Δsat −0,19 sur le
  balayage) — Lightroom aplatit la chroma avec le contraste négatif.
- **Hautes lumières −100** tire le BLANC à 234 et 224 → 175 ; +100 : 224 → 250,
  monte dès 32 (39). **Ombres +100** : 32 → 121, 64 → 139 (très fort, comme la
  planche 02 le montrait) ; −100 : 32 → 6. **Blancs +100** : écrête à partir de
  224 ; **Noirs −100** : 32 → 0, 64 → 6, 96 → 49.
- **Clarté +100** sur une rampe : 32 → 19, 160 → 171 — le rayon est GRAND (une
  rampe douce est amplifiée), **Texture** : rien sur la rampe (rayon fin).
- **Voile +100** : 128 → 45, 0 → 0 ; **−100** : 0 → 69 (ajoute du voile), 128 → 227.
- **Courbe paramétrique** : Teintes sombres +100 : 32 → 59, 96 → 151 ; Hautes
  lumières −100 : 192 → 161, 224 → 190 ; Ombres +100 : 32 → 58.

**Balance des blancs (JPEG, relative)** — ⚠️ **PAS normalisée en luminance** :
Température +100 éclaircit toute la rampe (128 → 180) et teinte fortement
(R−B = +119 à 128) ; −100 : 128 → 196 et R−B = −98. Nuance ±100 : idem (128 →
166 / 138), G−(R+B)/2 = −64 / +89. Le module 02 renormalise au blanc — écart
mesuré avec Lightroom, à trancher (Lightroom éclaircit, le nôtre garde la
luminance ; l'un des deux est « comme Lightroom », l'autre est meilleur).

**Vibrance / Saturation.** Saturation −100 : chroma −0,999 (désaturation
totale), lum +0,17. **Vibrance −100 : chroma −0,385 seulement**, lum +0,28.
+100 : sur un balayage déjà saturé à 100 %, aucun des deux ne monte (+0,001).
N&B : chroma −0,999, lum +0,19 (le mélange par défaut éclaircit).

**HSL — les bandes NE SONT PAS des gaussiennes symétriques, et l'amplitude est
grande.** Teinte +100 (décalage de sortie par teinte d'entrée, en ° HLS) :
- Rouge : pic **+50° à 343°**, actif de ~320° à ~30°, largeur à mi-hauteur 38°.
- Orange : pic +22° à ~352°/30°, large (56°) — chevauche le rouge.
- Vert : pic **+77° à 82°**, actif de 67° à 168°, largeur 66° — asymétrique
  (monte vite, redescend lentement vers le cyan).
- Bleu : pic **+88° à 202°**, actif de 185° à 286°, largeur 62°.
Les centres ne sont pas 0/30/60/120/180/240/270/300 : le « bleu » de Lightroom
est centré vers 205-220° (HLS), le « vert » vers 85-100°. `hsl-sat-bleu-m100`
: Δsat −0,16 en moyenne sur TOUT le balayage (la bande bleue est large) ;
`hsl-lum-vert-p100` : lum +0,11 en moyenne. → `assets/calibrer-hsl.py` doit
ajuster centres, largeurs ET forme (asymétrie) sur ces courbes, pas une
gaussienne centrée sur les teintes nominales.

**Étalonnage.** Bleu primaire teinte ±100 tourne le balayage ENTIER de
**∓23°** en moyenne (L 50 % et L 25 % pareil) ; Vert primaire +100 : +13° ;
Rouge primaire +100 : −1,2° en moyenne (mais sat −0,03, lum +0,06 — il agit
autrement). Bleu primaire saturation +100 : quasi rien sur un balayage saturé.
⚠️ **Nuance foncée ±100 : ZÉRO effet mesuré** — ni sur la rampe grise, ni sur
le balayage sombre. En JPEG, `ShadowTint` semble INERTE chez Lightroom. Notre
module 01 en porte une (index 0) : à trancher (garder comme extension, ou
retirer — un curseur mort chez la référence).

**Color Grading — ⚠️ MESURE INVALIDE pour Ombres et Hautes lumières.**
`grading-ombres-bleu`, `grading-hl-orange`, `balance`, `fusion` : zéro sur
tout. Seul `grading-moyens-vert` agit (gris à 128 : R−B −25, G−(R+B)/2 +56) et
`global-lum`. Cause probable : Lightroom stocke Ombres/Hautes lumières dans
les clés HÉRITÉES du virage partiel (`SplitToningShadowHue/Saturation`,
`SplitToningHighlightHue/Saturation`, `SplitToningBalance`), les clés
`ColorGradeShadow*`/`Highlight*` ne portant que la LUMINANCE. À re-mesurer
avec ces clés (liste `shaderlab-mesures-extra.txt`).

**Vignettage** : −100 assombrit jusqu'à 26 aux bords sur 255, +100 éclaircit
jusqu'à 254 — la rampe traverse le cadre, donc la « courbe » ici est le
PROFIL radial (milieu 50, contour 50, arrondi 0).
